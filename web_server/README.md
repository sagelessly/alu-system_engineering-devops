# Web server

Project on transferring files with scp, installing and configuring nginx, and setting up a domain name.

## Files

| File | Description |
|------|-------------|
| `0-transfer_file` | Transfers a file to a server with `scp` (4 parameters, strict host key checking disabled) |
| `1-install_nginx_web_server` | Installs nginx on port 80 serving a page containing `Holberton School` |
| `2-setup_a_domain_name` | The domain name configured with an A record pointing to the server |
| `3-redirection` | Configures `/redirect_me` as a 301 Moved Permanently redirect |
| `4-not_found_page_404` | Configures a custom 404 page containing `Ceci n'est pas une page` |
| `5-design_a_beautiful_404_page.html` | A designed 404 page |
